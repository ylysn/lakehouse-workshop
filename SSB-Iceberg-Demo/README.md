# SSB-Iceberg-Demo

SQL Stream Builder project for the Lakehouse Hands-on Labs: Kafka virtual tables for the airline
routes, countries and airports topics, and jobs that write them to Iceberg tables.

**Created by Steven Matison (Cloudera)**: original project at
[cldr-steven-matison/SSB-Iceberg-Demo](https://github.com/cldr-steven-matison/SSB-Iceberg-Demo).
Copied here for the CDP 7.3.2 v2 labs; the only change is the Kafka topic names in `tables/`
(`stevenmatison_*` → `admin_*`). Lab users select their own topics after importing.

Import in SSB: **Import** → Clone URL `https://github.com/ylysn/lakehouse-workshop`, branch `main`,
project `SSB-Iceberg-Demo`.
